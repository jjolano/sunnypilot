# Upstream touch points

Every modified upstream file, with one line on why. Custom behavior belongs in new files;
this list is the budget (target: <10 entries at end state) and the merge-conflict map for
upstream updates.

| File | Why |
|---|---|
| `common/params_keys.h` | Tailscale param keys (12) + custom long/lat opt-in params (incl. `CurveMemoryEnabled`, `LateralPreviewAssistMode`) + speed-aware torque params (3, incl. low-speed shadow toggle) + roll-compensation gain params (2) + moving-lead cruise-cap mode |
| `selfdrive/controls/controlsd.py` | Opt-in lateral demand pipeline hook (fail-closed call on the model-curvature branch, including lateral-delay handoff for preview assist), steering-override context for guarded curve memory, path-evidence handoff for the Torque v2.1 under-response guard, plus observability-only `modelPathState` publication (CPU: defaults filled only on non-success paths; was ~73 redundant capnp sets per 100Hz frame). REMAINING (harness-gated): wire lane-line y0 into `demand/wiring.build_pipeline_inputs` for lane-centering/DTLE refinement |
| `selfdrive/controls/lib/latcontrol_torque.py` | Extension hook + v0 shadow-mode underresponse sentinel wiring (no output changes) |
| `selfdrive/locationd/torqued.py` | Restructure collection gate so `lat_active && !steer_override` is the outer wrapper; add one extension call for shadow roll-compensation learning; keep strict path unchanged; populate `LiveTorqueParametersData` roll-comp telemetry via extension helper; persist speed/roll profiles on the 60s cache cadence |
| `sunnypilot/selfdrive/controls/lib/longitudinal_planner.py` | Opt-in custom-2.0 longitudinal hook in `update_targets` (import + adapter + 1 fail-closed call). Model-stop now read from upstream `modelV2.action.shouldStop`/`desiredAcceleration` (+ predicted stop distance derived from the model trajectory `position.x`/`velocity.x`) + coast from `get_coast_accel(pitch)` inside the adapter (no new planner touch). DEC bypassed in `is_e2e`/`update` when custom long is on (SCC replaces it) |
| `selfdrive/controls/lib/longitudinal_planner.py` | Cut-out lead release: 1 fail-closed call (`self.cut_out_release.filtered(...)`) shaping only the radarState handed to `mpc.update` — drops leadOne once it has confidently exited the path sideways (route 261; research-gated apply, raw pass-through otherwise). Dynamic follow-gap: 1 fail-closed call (`self.follow_gap.scheduled(...)`) computing the `t_follow` passed to `mpc.update` (returns the personality baseline when off/shadow/on fault; apply is research-gated). Moving-lead cruise cap: 1 fail-closed call (`self.moving_lead_cruise_cap.capped(...)`) lowering only the MPC cruise obstacle behind a mildly braking moving lead (shadow by default; apply research-gated). Gas-override coast helper: when driver gas pushes `vEgo` above the active cruise target, the cruise virtual obstacle is temporarily raised to `max(v_cruise, v_ego)` so speed coasts back naturally; cleared on brake/forceDecel/uninitialized target or when `vEgo` returns to target |
| `selfdrive/controls/lib/longitudinal_mpc_lib/long_mpc.py` | Decouple stop gap from moving follow distance: `STOP_DISTANCE` (4.5 m standstill buffer; 6 -> 5.5 for route 0000025a, -> 4.5 for route 00000261 — driver's manual stop median is 1.6 m radar gap) now fades with speed to `MOVING_GAP` (1.25 m) via `follow_offset(v)` in `get_safe_obstacle_distance` (the acados cost). Cuts the low-/mid-speed hang-back; stop gap + time-gap unchanged. Regenerated by the SConscript on build. `update(...)` gains an optional `t_follow=None` override (dynamic follow-gap scheduler); `None` keeps stock `get_T_FOLLOW(personality)` |
