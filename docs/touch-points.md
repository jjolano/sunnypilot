# Upstream touch points

Every modified upstream file, with one line on why. Custom behavior belongs in new files;
this list is the budget (target: <10 entries at end state) and the merge-conflict map for
upstream updates.

| File | Why |
|---|---|
| `common/params_keys.h` | Tailscale param keys (12) + custom long/lat opt-in params (incl. `CurveMemoryEnabled`, `LateralPreviewAssistMode`, default-off `CutOutLeadReleaseMode`, and the calibration-gated uphill net-demand cap) + speed-aware torque params (3, incl. low-speed shadow toggle) + roll-compensation gain params (2) + moving-lead cruise-cap mode |
| `selfdrive/controls/controlsd.py` | Hook-sized custom-lateral seam: one `conditioned_lateral_demand` call on the model-curvature branch (lifecycle, evidence extraction, and the pipeline live in `ControlsExt`/`sunnypilot/custom/lateral/demand/`), one `lateral_control_handoff` call (Torque v2.1 path evidence + override refresh), one live lateral-delay sample per control tick, and one `publish_lateral_telemetry` call (raw/conditioned/processed `modelPathState` serialization moved to `demand/telemetry.py`). Moving-lead cruise cap: 1 fail-closed call (`self.moving_lead_cruise_cap.capped(...)`) lowering only the MPC cruise obstacle behind a mildly braking moving lead (shadow by default; apply research-gated). Gas-override coast helper: when driver gas pushes `vEgo` above the active cruise target, the cruise virtual obstacle is temporarily raised to `max(v_cruise, v_ego)` so speed coasts back naturally; cleared on brake/forceDecel/uninitialized target, when `vEgo` returns to target, or after a bounded post-release window |
