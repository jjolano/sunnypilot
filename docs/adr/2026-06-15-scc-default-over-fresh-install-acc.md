# SCC remains the default for custom-2.0

Status: accepted

Custom-2.0 keeps SCC as the default longitudinal mode. SCC is the DEC replacement and the
intended blended behavior for fresh installs, while ACC remains an explicit opt-in mode for
OEM-like cruise semantics.

This supersedes the legacy fresh-install ACC default. The default must match the replacement
behavior users expect from custom-2.0, without changing the explicit ACC mode itself.
